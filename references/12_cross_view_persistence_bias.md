# 12 — Cross-View, Persistence, and Bias Guard

## Cross-view confirmation

When a candidate reaches PLAUSIBLE and map/satellite data are available, compare:
- building footprint/orientation;
- road geometry;
- adjacent structures;
- terrain slope;
- forest edge;
- coastline;
- open spaces;
- access path.

Ground-view and aerial-view evidence are independent only when they rely on different physical structure than the clue that generated the candidate.

## Persistence class

Tag clues when relevant:

- `STRUCTURAL`: expected to persist for years/decades; e.g. façade geometry, road alignment.
- `SEMI_PERSISTENT`: may change; e.g. paint, vegetation form, signage.
- `TRANSIENT`: short-lived; e.g. parked car, temporary banner, weather.

Prefer STRUCTURAL evidence for identity. Use transient evidence mainly as supporting context.

## Search-abundance bias guard

`SEARCH ABUNDANCE IS NOT GEOGRAPHIC EVIDENCE.`

A candidate with many indexed photos/results is not more correct merely because it is better documented online.

Do not award score for result count, popularity, tourism prominence, or dataset familiarity.

## Opportunistic secondary criteria

Use only when supported and useful:
- sun/shadow consistency;
- ecological assemblage rather than single-species guesses;
- geology/building material provenance;
- settlement/network morphology;
- multi-season or multi-view reference consistency.

Never make these mandatory universal gates.
