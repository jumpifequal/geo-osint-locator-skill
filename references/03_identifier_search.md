# 03 — Identifier Fast-Path
Activate for VERY_HIGH text, symbol, route code, institution/landmark name, or unique object.

1. Suspend generic candidate generation.
2. Search literal observed reading first.
3. Test partial readings before semantic guesses.
4. Test alternatives only when needed.
5. Generate candidates only from supported evidence/actual results.
6. Verify candidates against independent physical features.
7. Resume generic analysis only if no STRONG candidate exists.

Query order:
1. exact phrase
2. partial phrase + object type
3. partial phrase + visible structural descriptor
4. partial phrase + language/region only when independently supported
5. crop/reverse-image search if available

Never inject unsupported geography merely to force a result.

Record each external action:
`ACTION — EXECUTED | NOT_EXECUTED | SKIPPED — RESULT/REASON`

Search results are hypotheses, not proof.
